# 기본 내용·장표 수정 — 원본 강의 기반 프롬프트

## 1. 글자 크기·가독성

사용 시점: 완성 화면에서 글자가 너무 작거나 줄이 어색할 때

> 전체 텍스트 크기를 조금 더 키워줘. 한글은 단어 중간에서 잘리지 않게 하고 제목·본문의 대비를 유지해줘.

## 2. 장표·페이지 추가

사용 시점: 정보가 누락되어 특정 위치에 장표를 추가해야 할 때

> 2페이지와 3페이지 사이에 [추가할 내용]을 조사하고 검증 가능한 출처를 붙여 새 페이지를 추가해줘. 기존 페이지는 유지해줘.

## 3. 장표·페이지 삭제

사용 시점: 불필요한 구성 삭제

> [삭제할 페이지 번호] 페이지를 삭제해줘. 이후 페이지 번호와 연결도 정상 반영해줘.

## 4. 페이지 순서 변경

사용 시점: 스토리 흐름이 어색한 경우

> [페이지 A]와 [페이지 B]의 순서를 서로 바꿔줘. 내용과 상호작용은 유지해줘.

## 5. 상시 편집 모드

사용 시점: 사용자가 반복해서 편집 모드 추가·해제 요청하는 불편 방지

> 제작 화면에는 클릭해서 직접 글자를 수정하는 편집 기능을 기본 탑재해줘. 변경 사항을 저장하고 다시 열면 계속 편집할 수 있게 해줘.

## 6. 편집기 없는 HTML 출력

사용 시점: 강의의 편집 해제 단계를 내보내기로 대체

> HTML 저장 버튼을 추가해줘. 배포용 HTML에는 편집 도구나 편집 UI가 보이지 않아야 한다. 출력한 HTML을 다시 제작 화면에 가져와 재편집하는 것도 가능해야 한다.

## 10. 요소 순차 등장

사용 시점: 발표자가 Enter 또는 클릭으로 설명을 나누고 싶을 때

> 표지를 제외한 각 장표를 빈 상태에서 시작하고 클릭 또는 Enter마다 요소가 순서대로 등장하게 해줘. 키보드와 터치에서도 동작해야 해.

## 11. 자동 발표

사용 시점: 무인 시연이나 자동 발표에 활용

> 발표 시작하기 버튼을 누르면 2페이지부터 자동 발표해줘. 일시정지·다시 시작·수동 넘기기 기능도 넣어줘.
