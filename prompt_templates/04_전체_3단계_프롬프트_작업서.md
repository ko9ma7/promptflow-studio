# 나의 새 프로젝트 — 강의 기반 단계별 프롬프트 작업서

## 진행 원칙
1단계를 복사해서 외부 AI에 전달하고 첨부 파일은 실제로 업로드합니다. 결과를 확인한 뒤 2단계는 필요한 수정 프롬프트만 한 번씩 전달합니다. 고급 효과 및 모션은 선택 사항입니다.

## 1단계 · 초안

@Sites

# 1단계 · 영상 방식 마스터 초안 프롬프트

첨부한 폴더의 자료를 기반으로 '나의 새 프로젝트'에 대한 HTML 인터랙티브 발표 슬라이드를 제작해줘.

- 제작 목표: 주제와 첨부 자료를 분석하여 핵심 목표 제안
- 발표·독자 대상: 자료에 맞는 독자 제안
- 분량: 7장 내외
- 레이아웃·디자인: 폴더 속 '디자인 레퍼런스'를 참고하고 깔끔하고 가독성 높은 전문가형으로 통일
- 참고 디자인: https://kr.pinterest.com/
- 폰트: [눈누 폰트 URL 또는 저작권 확인된 한글 폰트]; 한글은 단어 중간에 줄이 끊기지 않게 처리
- 이해를 돕는 도표·이미지: 직접 생성할 수 있으나 실제 사진/수치는 추측하지 말고 표시·출처 확인
- 숫자가 들어간 장은 데이터에 맞는 Chart.js 차트 선택: https://www.chartjs.org/docs/latest/samples/information.html
- 필요한 상호작용·전환 효과 참고: https://seoul-one-day-many-stories.pegeechmco.chatgpt.site/
- 제작 화면에는 클릭형 편집 모드를 항상 기본 제공해줘. 'HTML 저장'을 누르면 편집 메뉴·핸들·툴바가 빠진 배포용 HTML 파일로 저장해야 해. 저장한 HTML을 나중에 제작 화면으로 불러오면 다시 수정할 수 있도록 구조 데이터를 보존해줘. 보고·발표 화면에서 편집 UI는 절대 나타나지 않게 해줘. 필요하면 16:9 PPT 규격에 맞는 이미지 PNG와 PPTX 출력도 지원해줘.
- 참고 자료: 첨부 파일을 먼저 분석하고 근거, 기준일, 수치의 단위와 출처를 표시

기본 단계에서는 내용·구성·가독성을 우선해. **레버·팝업·고급 전환·모션그래픽은 추가 요청한 기능만 구현**해줘.

먼저 전체 7장의 스토리라인을 제시하고, 각 페이지의 핵심 메시지와 레이아웃을 설계한 다음, 실제 실행 가능한 파일을 제작해줘.

## 2단계 · 기본 수정 메뉴

### 1. 글자 크기·가독성
언제: 완성 화면에서 글자가 너무 작거나 줄이 어색할 때
전체 텍스트 크기를 조금 더 키워줘. 한글은 단어 중간에서 잘리지 않게 하고 제목·본문의 대비를 유지해줘.

### 2. 장표·페이지 추가
언제: 정보가 누락되어 특정 위치에 장표를 추가해야 할 때
2페이지와 3페이지 사이에 [추가할 내용]을 조사하고 검증 가능한 출처를 붙여 새 페이지를 추가해줘. 기존 페이지는 유지해줘.

### 3. 장표·페이지 삭제
언제: 불필요한 구성 삭제
[삭제할 페이지 번호] 페이지를 삭제해줘. 이후 페이지 번호와 연결도 정상 반영해줘.

### 4. 페이지 순서 변경
언제: 스토리 흐름이 어색한 경우
[페이지 A]와 [페이지 B]의 순서를 서로 바꿔줘. 내용과 상호작용은 유지해줘.

### 5. 상시 편집 모드
언제: 사용자가 반복해서 편집 모드 추가·해제 요청하는 불편 방지
제작 화면에는 클릭해서 직접 글자를 수정하는 편집 기능을 기본 탑재해줘. 변경 사항을 저장하고 다시 열면 계속 편집할 수 있게 해줘.

### 6. 편집기 없는 HTML 출력
언제: 강의의 편집 해제 단계를 내보내기로 대체
HTML 저장 버튼을 추가해줘. 배포용 HTML에는 편집 도구나 편집 UI가 보이지 않아야 한다. 출력한 HTML을 다시 제작 화면에 가져와 재편집하는 것도 가능해야 한다.

### 10. 요소 순차 등장
언제: 발표자가 Enter 또는 클릭으로 설명을 나누고 싶을 때
표지를 제외한 각 장표를 빈 상태에서 시작하고 클릭 또는 Enter마다 요소가 순서대로 등장하게 해줘. 키보드와 터치에서도 동작해야 해.

### 11. 자동 발표
언제: 무인 시연이나 자동 발표에 활용
발표 시작하기 버튼을 누르면 2페이지부터 자동 발표해줘. 일시정지·다시 시작·수동 넘기기 기능도 넣어줘.

## 2단계 · 추가 효과 (선택)

### 7. 숫자·그래프 채우기
언제: 데이터를 강조할 때
숫자와 그래프에 마우스를 대면 부드럽게 값이 채워지는 효과를 추가해줘. 터치 환경에서는 클릭으로 동작해줘.

### 8. 제품 사양 레버
언제: 옵션을 바꾸면 이미지·정보를 함께 보여줄 때
선택 가능한 세로 레버를 추가해줘. Performance / Thrust / Rocket을 선택하면 관련 사양, 설명, 이미지가 동시에 바뀌도록 해줘.

### 8-1. 연도별 데이터 연동
언제: 기간별 데이터와 재무 차트를 비교할 때
2023, 2024, 2025 버튼을 클릭하면 매출, 생산량, 주요 재무 수치 및 그래프가 선택 연도에 따라 함께 변경되도록 해줘.

### 9. 하단 상세 패널
언제: 기본 화면은 간결하게, 상세 정보는 클릭 후 표시
상세 항목을 누르면 아래에서 상세 패널이 올라오도록 만들어줘. 주변은 어둡게 하되 흐림 효과는 넣지 말고, ESC와 닫기 버튼으로 닫을 수 있게 해줘.

## 3단계 · 모션그래픽 (선택)

# 3단계 · 모션그래픽 (선택 사항)

첨부한 '모션그래픽 레퍼런스'를 참고해서 '나의 새 프로젝트'을 홍보하는 15초 모션그래픽을 제작해줘. 역동적으로 구성하되 영상의 메시지는 분명하게 해줘.
발표 화면에 맞는 16:9 비율로 제작해줘.
음악은 넣지 말아줘.
영상은 오프닝·엔딩 또는 페이지 전환에 넣을 수 있는 파일로 만들어줘. 이후 슬라이드에 실제 파일을 연결하고 자동재생 제한과 재생 실패에 대응해줘.

### 12. 15초 모션그래픽
첨부한 모션그래픽 레퍼런스 영상을 참고해서 [홍보 대상]의 15초 모션그래픽 영상을 만들어줘. 최대한 역동적이고 핵심 메시지를 분명하게 표현해줘.

### 13. 영상 중간 삽입
만든 영상을 1페이지와 2페이지 사이에 삽입해줘. 전체화면으로 자동재생하고 브라우저의 자동재생 제한에 대응해줘.

### 13-1. 마지막 페이지 영상
만든 영상을 마지막 페이지에 넣어줘. 마지막 페이지의 제목을 [마지막 메시지]로 해줘.

### 14. 세로형 쇼츠
위 모션그래픽을 9:16 쇼츠용으로도 만들어줘.

### 15. 무음 버전
음악은 넣지 말아줘. 필요하면 무음 자막 버전으로 만들어줘.

## 결과 검수와 재질문
AI의 답변과 결과를 붙여넣고 미흡 항목에 '어떤 페이지에서 / 어떤 동작이 / 어떻게 바뀌어야 하는지'를 명시합니다. 기존 기능은 유지하도록 요청합니다.
